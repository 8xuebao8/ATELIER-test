# 琢光 Atelier · 珠宝设计工作台

纯 HTML、CSS 和 JavaScript 编写的静态珠宝设计工具。所有样式和逻辑都在 `index.html` 内，可直接用浏览器打开，无需安装依赖或配置服务器。

## 使用流程

1. 上传 JPG、PNG、WEBP 图片，或使用示例设计稿。
2. 选择「设置参考尺寸」，点击已知距离的两端，输入实际毫米数。
3. 使用直线或直径测量工具进行标注；可拖动端点或用方向键微调。
4. 添加圆形、椭圆、水滴或祖母绿切形宝石，调整尺寸、颜色、角度，支持复制和镜像。
5. 导出 PNG 设计图，或保存 `.jewel.json` 项目文件供下次继续编辑。

## 数据与保存

照片只在本地浏览器处理，不上传服务器。自动保存仅适用于当前浏览器和网址，重要设计请下载项目文件备份。大图会等比缩小至最长边 2200 像素，校准基于处理后的图片。

## 快捷键

V 选择，C 校准，M 直线，D 直径，H 平移。滚轮缩放，空格拖动；Esc 取消，Delete 删除，Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 重做。属性修改后按回车或移开焦点应用。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 `main` 分支的根目录 `/ (root)`。

## 测量说明

尺寸是单一平面上的照片比例估算，倾斜拍摄、透视或不同深度会造成误差，不能替代实物测量。宝石图形用于构图与尺寸预览，不是生产 CAD 模型。
